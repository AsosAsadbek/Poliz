POLIZ qanday işlaydi

POLIZ — arifmetik va mantiqiy ifodalarni kompyuter tomonidan qulay qayta işlaş uçun maxsus körinişda yoziş usuli. Atama rus tilidagi «ПОЛЬская Инверсная Запись» — Polşa invers yozuvi (Reverse Polish Notation, RPN) nomidan kelib çiqqan.

Oddiy yozuvda operator operandlar orasida turadi: A+B. POLIZda esa operator operandlardan keyin yoziladi: A B +.

1. Oddiy yozuv va POLIZ

(A+B)*CA B + C *
A+B*CA B C * +
(A-B)/(C+D)A B - C D + /

POLIZda qavslar va operatorlar ustuvorligini alohida hisobga oliş zarurati yöqoladi.

2. POLIZ stek yordamida hisoblanadi

Asosiy qoida:

  • Operand uçrasa — stekka joylanadi.
  • Ikki operandli operator uçrasa — stekdan ikkita operand olinadi, amal bajariladi va natija stekka qaytariladi.
  • Oxirida stekda qolgan yagona qiymat — natija.

Masalan, (5+3)*2 → 5 3 + 2 *: 5 va 3 stekka joylanadi; + kelganda 5 va 3 olinadi → 5+3=8, 8 stekka qaytariladi; 2 joylanadi; * → 8*2=16.

3. POLIZni hosil qiliş (Deykstraning «saralaş stansiyasi»)

  • Operand (son yoki özgaruvçi) — darhol çiqişga yoziladi.
  • Operator — stek tepasidagi ustuvorligi yuqoriroq (yoki teng va çapdan assotsiativ) operatorlar çiqişga ötkaziladi, söng yangi operator stekka qöyiladi.
  • ( stekka qöyiladi; ) kelsa — ( gaça bölgan operatorlar çiqişga ötkaziladi, qavslar taşlanadi.
  • Ifoda tugagaç, stekda qolgan operatorlar çiqişga ötkaziladi.

Murakkab misol: (A+B)*(C-D)/E → A B + C D - * E /

4. Nima uçun muhim

POLIZ kompilyatorlar va interpretatorlar faoliyatida muhim tuşunça. Dasturçi x = (a + b) * c; deb yozsa, uning POLIZ körinişi x a b + c * = böladi va ifodani stek yordamida ketma-ket bajariş osonlaşadi.

Kiritiş

  • Kasr sonlar: 3.5 yoki 3,5; manfiy son: -5 yoki (-5).
  • Özgaruvçilar: A, b, x1. Ularga qiymat bersangiz — son natija ham çiqadi.
  • Muqobil belgilar: × · → *, ÷ : → /, ** → ^, [ ] { } → qavs. Oxiridagi ; eʼtiborga olinmaydi.
  • Jadvaldagi qatorni tanlasangiz, mos belgi ifodada ajratib körsatiladi.
